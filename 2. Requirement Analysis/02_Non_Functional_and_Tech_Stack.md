# Non-Functional Requirements and Technology Stack

## Non-Functional Requirements
- Usability: simple navigation and clear forms.
- Responsiveness: usable on desktop and mobile screens.
- Reliability: validate budget input before generation.
- Maintainability: keep the prototype self-contained and readable.
- Privacy: do not publish real API keys in GitHub.
- Transparency: identify AI-generated estimates and limitations.

## Technology Stack
- HTML5
- CSS3
- JavaScript
- Browser LocalStorage for prototype history/settings
- Google Gemini REST API for live generation
- GitHub for version control and submission

## Single-File Constraint
The current prototype intentionally keeps the application in one HTML file so it can be demonstrated without installing a backend or package manager.
