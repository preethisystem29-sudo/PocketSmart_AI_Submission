# Functional Requirements

FR1. The system shall accept a budget in Indian Rupees.
FR2. The system shall accept a recommendation category.
FR3. The system shall accept a free-text requirement.
FR4. The system shall accept preferences and constraints.
FR5. The system shall optionally accept quantity/number of people.
FR6. The system shall calculate planned spending and remaining budget.
FR7. The system shall generate a Gemini-based recommendation.
FR8. The AI prompt shall instruct the model not to exceed the user's budget.
FR9. The result shall contain a summary, budget allocation, reasoning, alternatives and tips.
FR10. The user shall be able to save a generated recommendation.
FR11. Saved recommendations shall be viewable from History.
FR12. The user shall be able to clear saved history.
FR13. The application shall provide Demo Mode without a Gemini API key.
FR14. The application shall allow the Gemini model/API key to be configured in Settings.
