# PocketSmart AI — Project Idea

## Project Title
PocketSmart AI: Your Smart Budget & Recommendation Assistant

## Problem Statement
People often have a fixed budget but struggle to decide how to allocate it across a purchase, event, or personal requirement. Generic recommendations may ignore the user's actual budget and preferences.

## Proposed Solution
PocketSmart AI is a Gemini-powered assistant that accepts a user's category, budget, requirement, quantity and preferences, then generates a personalized, budget-aware recommendation. The application also allows users to save and review previous recommendations.

## Target Users
- College students
- Young adults
- Budget-conscious consumers
- People planning small events
- Users making personal purchase decisions

## Core Value
Budget first, recommendation second: the user's budget acts as a constraint for the generated plan.

## Example Use Cases
- Interior planning
- Jewelry planning
- Party planning
- Electronics/personal purchase planning
- Travel planning

## Key Features
1. Budget input and validation
2. Budget utilization calculation
3. Gemini-powered recommendation generation
4. Budget allocation in INR
5. Alternative/trade-off suggestions
6. Recommendation history
7. Demo mode without an API key
