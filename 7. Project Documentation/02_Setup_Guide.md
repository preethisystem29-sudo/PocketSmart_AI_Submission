# Setup Guide

## Demo Mode
1. Download/clone the repository.
2. Open `PocketSmart_AI.html`.
3. Select AI Recommendation.
4. Enter a category and budget.
5. Click Try Demo Mode.

## Live Gemini Mode
1. Obtain a Gemini API key from your Google AI/Gemini API environment.
2. Open Settings.
3. Paste the key.
4. Choose an available Gemini model.
5. Save Settings.
6. Generate a recommendation.

## GitHub Safety
Never commit a real API key. If you move to a backend deployment, store the key in an environment variable or secret manager.
