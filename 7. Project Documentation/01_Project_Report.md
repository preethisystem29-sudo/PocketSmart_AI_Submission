# PocketSmart AI — Project Report

## Abstract
PocketSmart AI is a Gemini-powered budget and recommendation assistant. The application allows users to specify a budget, category, requirement, preferences and optional quantity. It generates a personalized recommendation with a budget allocation, reasoning, alternatives and practical tips. Recommendations can be saved and revisited through browser-based history.

## Problem
Budget-conscious users may find it difficult to translate a fixed amount of money into a practical plan. Generic recommendation systems may not account for the user's exact budget or preferences.

## Solution
PocketSmart treats the budget as a key constraint and uses Gemini generative AI to produce a structured recommendation. A lightweight single-file architecture makes the prototype easy to run and demonstrate.

## Objectives
- Budget-aware recommendations.
- Simple user experience.
- Generative AI integration.
- Recommendation history.
- Clear explanation of trade-offs.

## Features
- Dashboard
- Budget planner
- AI recommendation
- Demo mode
- History
- Settings
- Responsive UI

## Technology
HTML5, CSS3, JavaScript, LocalStorage, Google Gemini REST API and GitHub.

## Limitations
This prototype does not provide verified live product prices, does not connect to bank accounts, and is not intended as regulated financial advice.
