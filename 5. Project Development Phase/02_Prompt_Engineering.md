# Gemini Prompt Design

The prompt establishes PocketSmart as a budget-aware recommendation assistant.

## Prompt Rules
- Include category, budget, requirement, preferences and quantity.
- Treat the budget as a constraint.
- Ask for 3–6 allocation categories.
- Ensure the estimated total does not exceed the budget.
- Label suggested amounts as estimates.
- Avoid claiming live prices or availability unless supplied.
- Provide reasoning, alternatives and practical tips.
- Include a verification note.

## Example
Category: Interior Planning
Budget: ₹50,000
Requirement: Modern bedroom for a student
Preferences: Minimal, durable, space-saving

The generated result should prioritize the main requirement and retain a sensible reserve.
