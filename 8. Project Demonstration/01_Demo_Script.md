# PocketSmart AI — Demo Script

## 0:00–0:20 — Introduction
“PocketSmart AI is a Gemini-powered budget and recommendation assistant. The user gives us a budget and requirement, and the system generates a personalized plan while respecting the budget.”

## 0:20–0:45 — Dashboard
Show the dashboard and explain the budget, planned spending, remaining amount and saved-plan counters.

Enter:
Budget: ₹50,000
Planned spend: ₹42,000

Show the utilization calculation.

## 1:10–2:00 — AI Recommendation
Use:
Category: Interior Planning
Budget: ₹50,000
Requirement: Modern, space-saving bedroom for a college student
Preferences: Minimal, durable, keep a reserve

Generate the recommendation.

## 2:00–2:25 — Explain AI Output
Point out:
- Summary
- Allocation
- Reasoning

- Tips

## 2:25–2:45 — Save and History

“The prototype demonstrates a complete flow from budget input to generative AI recommendation and persistent history. Future versions can add secure backend access and live product data.”
