# PocketSmart AI — Your Smart Budget & Recommendation Assistant

PocketSmart AI is a Gemini-powered web prototype that generates personalized, budget-aware recommendations from a user's category, budget, requirement, preferences and optional quantity.

## Core Features
- Budget planner
- Budget utilization
- Gemini AI recommendation
- Demo mode
- Recommendation history
- Responsive interface
- INR support
- Configurable Gemini model

## Run
Open `PocketSmart_AI.html` in a modern browser.

Demo Mode requires no API key.

Live Gemini mode can be configured from Settings. Do not publish a real API key.

## Project Flow
User → Budget & Requirement → Validation → Prompt Builder → Gemini → Recommendation → History

## Important Limitation
This is a student/classroom prototype. It does not verify live product prices or availability and is not regulated financial advice.
